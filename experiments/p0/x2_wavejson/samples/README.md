# X2 샘플

SPEC 문서에서 잘라 낸 타이밍 다이어그램과 사람이 작성한 정답 WaveJSON을 같은 이름으로 둡니다.

```
samples/
  rd_burst.png     # 그림
  rd_burst.json    # 정답 WaveJSON
```

- 최소 10장, 가능하면 20장 이상을 둡니다. 클럭 1개짜리 단순 파형, 버스 값이 있는 파형, 신호 8개 이상인 복잡한 파형, 다중 클럭 파형을 고루 섞습니다.
- 정답의 wave 문자열은 한 글자가 한 클럭 사이클이 되게 씁니다. 그림에 `|` 같은 생략 표시가 있으면 정답에도 같은 자리에 둡니다.
- 버스 값은 `=`와 `data` 라벨로 씁니다. 라벨은 그림에 적힌 그대로 씁니다.
- 실제 SPEC 그림은 사내 자료이므로 이 디렉터리를 외부 저장소에 올리지 않습니다.
