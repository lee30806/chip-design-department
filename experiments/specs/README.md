# 예시 SPEC 원본

예시로 쓸 SPEC 원본(PDF, Word, 엑셀, Visio)을 이 폴더에 둡니다. 이 폴더의 파일은 `.gitignore`로 제외되어 저장소에 올라가지 않습니다.

## 예시 SPEC

| SPEC | 대상 | 받는 곳 | 파일 |
| --- | --- | --- | --- |
| MIPI I3C Basic v1.2 | controller ([examples/i3c_basic_controller](../../examples/i3c_basic_controller/)) | [MIPI I3C Basic 다운로드](https://www.mipi.org/mipi-i3c-basic-download) (양식 제출 후 받음) | `MIPI-I3C-Basic-Specification-v1-2-public-edition-er01.pdf` (Errata 01 반영본) |

## 주의

MIPI 등 외부 SPEC은 공개본이라도 재배포 조건이 있으므로 저장소에 커밋하지 않습니다. 저장소에는 이 SPEC을 변환하고 정리한 결과물만, 출처를 밝혀 올립니다.
